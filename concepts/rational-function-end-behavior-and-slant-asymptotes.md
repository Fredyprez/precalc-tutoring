# Rational Function End Behavior and Slant Asymptotes

For rational functions, there are three main cases for end behavior:

- If the numerator's degree is less than the denominator's, the horizontal asymptote is \(y=0\).
- If the degrees are equal, the horizontal asymptote is the ratio of the leading coefficients.
- If the numerator's degree is greater than the denominator's, polynomial division is needed. If the numerator's degree is exactly one greater than the denominator's, the result is a slant asymptote.
